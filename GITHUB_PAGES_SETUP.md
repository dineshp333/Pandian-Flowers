## 📋 Step-by-Step: Deploy to GitHub Pages (FREE!)

### Step 1: Create a GitHub Account (if you don't have one)
1. Go to **https://github.com/signup**
2. Enter your email, create password
3. Choose username (e.g., `pandianflowers` or your name)
4. Verify email
5. ✅ Account created!

### Step 2: Create a New Repository on GitHub
1. Login to GitHub
2. Click **"+" button → New repository**
3. **Fill in:**
   - **Repository name:** `pandian-flowers` (or any name)
   - **Description:** Pandian Flowers - Beautiful flower garlands in Coimbatore
   - **Public** (so it's visible to everyone)
   - **Do NOT initialize with README** (we have one)
4. Click **"Create repository"**
5. You'll see **Quick setup instructions**

### Step 3: Connect Local Repo to GitHub
Copy these commands in **PowerShell** in your project folder:

```powershell
cd "d:\AI Journey\Pandian Flowers"

git remote add origin https://github.com/YOUR_USERNAME/pandian-flowers.git
git branch -M main
git push -u origin main
```

**Replace `YOUR_USERNAME` with your actual GitHub username!**

### Step 4: Enable GitHub Pages
1. Go to your GitHub repository
2. Click **Settings** tab
3. Scroll left to **Pages**
4. Under "Build and deployment":
   - **Source:** Select "Deploy from a branch"
   - **Branch:** Select "main" and "/(root)"
   - Click **Save**
5. Wait 2-3 minutes for deployment
6. You'll see: "Your site is live at: `https://YOUR_USERNAME.github.io/pandian-flowers/`"

## 📊 Submit to Google Search Console (Make it Searchable)

### Step 1: Go to Google Search Console
1. Visit **https://search.google.com/search-console**
2. Click **"Start now"**
3. Sign in with your Google account

### Step 2: Add Property
1. Select **"URL prefix"**
2. Enter your live website URL:
   ```
   https://YOUR_USERNAME.github.io/pandian-flowers/
   ```
3. Click **Continue**

### Step 3: Verify Ownership
- **Easy method:** Copy the HTML meta tag
- Go to your `index.html`
- Paste the meta tag in `<head>` section
- Push changes to GitHub
- Come back and click **Verify**

### Step 4: Submit Sitemap
1. In Google Search Console, go to **Sitemaps**
2. Enter: `sitemap.xml`
3. Click **Submit**
4. ✅ Google will crawl your website!

# Pandian Flowers Website

A beautiful, responsive flower shop website built with HTML, CSS, JavaScript, and Tailwind CSS.

## 🌸 About

Pandian Flowers is a premium flower shop specializing in:
- Wedding Garlands
- Reception Decorations
- Home Nilavu (traditional home decorations)
- Custom Garland Designs
- Event Decorations

## 📁 Project Structure

```
pandian-flowers/
│
├── index.html          # Home page with hero banner and featured garlands
├── about.html          # About us page with our story and values
├── gallery.html        # Gallery with categorized garland collections
├── services.html       # Services page with detailed offerings
├── order.html          # Order form for customers
├── contact.html        # Contact page with form and map
│
├── css/
│   └── style.css      # Custom CSS with color themes and animations
│
├── js/
│   └── script.js      # JavaScript for interactivity and form validation
│
├── images/
│   ├── wedding/       # Wedding garland images
│   ├── reception/     # Reception decoration images
│   └── home/          # Home nilavu images
│
├── components/
│   ├── header.html    # Reusable header component
│   └── footer.html    # Reusable footer component
│
└── README.md          # This file
```

## 🎨 Features

- **Responsive Design**: Mobile-friendly layout that works on all devices
- **Tailwind CSS**: Modern utility-first CSS framework for styling
- **Custom Animations**: Smooth transitions and hover effects
- **Form Validation**: Client-side validation for order and contact forms
- **Interactive Gallery**: Filterable gallery with category tabs
- **Testimonials**: Customer reviews section
- **SEO Optimized**: Meta tags and semantic HTML

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- A text editor (VS Code, Sublime Text, etc.)
- Git (optional, for version control)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/pandian-flowers.git
cd pandian-flowers
```

2. Open `index.html` in your browser:
```bash
# On Windows
start index.html

# On Mac
open index.html

# On Linux
xdg-open index.html
```

Or simply double-click the `index.html` file.

### Development

No build process required! This is a static website that runs directly in the browser.

To make changes:
1. Edit the HTML, CSS, or JavaScript files
2. Refresh your browser to see changes
3. Commit your changes to Git

## 📸 Adding Images

To add your own images:

1. Place images in the appropriate folders:
   - `images/wedding/` for wedding garlands
   - `images/reception/` for reception decorations
   - `images/home/` for home nilavu

2. Update the HTML files to reference your images:
```html
<img src="images/wedding/garland1.jpg" alt="Wedding Garland">
```

## 🚀 Deployment

### GitHub Pages

1. Push your code to GitHub
2. Go to repository Settings > Pages
3. Select branch (main) and folder (root)
4. Your site will be live at `https://yourusername.github.io/pandian-flowers/`

### Other Hosting Options

- **Netlify**: Drag and drop deployment
- **Vercel**: Connect GitHub repository
- **Firebase Hosting**: `firebase deploy`
- **Traditional Hosting**: Upload files via FTP
